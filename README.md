# React JS Practical Record

This repository contains the student's digital React JS practical record.

## Student Tasks

1. Open `index.html`.
2. Enter your:
   - Name
   - Register Number
   - Class
   - Dates
3. Replace `PROGRAM_01_URL` to `PROGRAM_20_URL` with the published GitHub Pages URLs of your 20 practical repositories.
4. Replace the program titles with the actual practical titles.
5. Commit and push the changes.
6. Enable GitHub Pages.
7. Submit the GitHub Pages URL of this record.

## Example

```text
https://studentusername.github.io/ReactJS-Practical-Record/
```

## Important

The 20 practical programs are maintained in separate repositories.
This repository acts as the student's master practical-record index.
